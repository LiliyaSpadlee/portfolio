Библиотечная система
Информационная система управления библиотечной сетью, сотрудниками, книжными фондами и поставками литературы.

Технологии
Бэкенд: PHP (MySQLi), сессии
База данных: MySQL, MySQL Workbench
Архитектура БД: хранимые процедуры, триггеры автоматизации (контроль зарплат, обновление остатков фондов), аналитические представления
Интерфейс: HTML, CSS, JavaScript

Основной функционал
Каталог изданий: поиск по книгам, журналам и газетам с фильтрами.
Управление персоналом: учет сотрудников, зарплат и стажа.
Фонды и пополнения: сводная статистика по филиалам и учет поступлений литературы.
Демо-режим: быстрый вход в панель управления для проверки функционала.

Инструкция по локальному запуску
Установите и запустите локальный сервер XAMPP (Apache и MySQL).
Создайте базу данных с именем usm в phpMyAdmin.
Импортируйте SQL-скрипты из проекта в созданную базу данных.
Скопируйте папку проекта в директорию C:\xampp\htdocs.

Откройте в браузере адрес:
Если у вас стандартные настройки портов в XAMPP, введите:
http://localhost/library_site/

Если порт Apache изменен (например, на 8080, как часто бывает при конфликтах портов), обязательно укажите его через двоеточие
http://localhost:8080/library_site/
